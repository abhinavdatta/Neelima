Neelima Browser Bridge

Settings and compatible-site configuration

AI website integrations

Enable only the sites you want the extension to interact with. A website adapter does not grant filesystem access; Neelima's backend enforces workspace permissions.

Permission mode

Display preference only. Neelima desktop backend is the only authority for permissions; this extension setting never authorizes a file operation.

Generic compatible website

Grant the extension access to one HTTPS domain at a time. Enter a hostname only, such as example.com. This is a browser permission, not permission to access local files.

    Workspaces

    Workspaces are selected and authorized inside Neelima. This extension does not browse or grant access to PC folders by itself.
